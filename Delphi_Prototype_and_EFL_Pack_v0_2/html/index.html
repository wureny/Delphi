Design doctrine

四条不能被代码 Agent 稀释的原则

Delta over document

首页展示“变化及其影响”，而不是另一篇长报告。

Proposal before mutation

模型可以提案，只有授权用户可以改变正式状态。

Honest degradation

缺失证据必须显式阻断结论，不能用看似合理的文本填空。

State outlives models

模型和 Agent SDK 可替换，正式状态、权限、历史和评测长期存在。
