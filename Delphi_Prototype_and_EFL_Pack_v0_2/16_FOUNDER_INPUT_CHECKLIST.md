# Delphi Founder Input Checklist

**Purpose:** resolve every fact that must not be guessed before EFL submission, investor outreach, or customer materials.

Mark each item with:

```text
[CONFIRMED]
[IN PROGRESS]
[UNKNOWN]
[NOT APPLICABLE]
```

---

## 12. Final truth test

For every sentence in the application, ask:

1. Is this true today?
2. Can we show evidence?
3. Is it a current capability, a target architecture, or a hypothesis?
4. Would a customer interpret it more strongly than intended?
5. Does another document contradict it?
6. Is a number dated and defined?
7. Are we accidentally combining an old prototype with a new product claim?

If uncertain, qualify or remove it.
